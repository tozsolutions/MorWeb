BÖLÜM 2: NETLIFY İLE ÜCRETSİZ YAYINLAMA (EN KOLAY YOL)
================================================================

ADIM 1: Netlify Hesabı Aç
  → https://netlify.com adresine git
  → "Sign up" → "Sign up with Google" seç
  → Google hesabınla giriş yap (ücretsiz)

ADIM 2: Siteyi Yükle
  → Netlify'a giriş yaptıktan sonra ana sayfada
    "Sites" sekmesine tıkla
  → Büyük kutunun içine şunu görürsün:
    "Drag and drop your site folder here"
  → Seçtiğin klasörü (örn: TOZYAPIWEB/1) olduğu gibi
    bu kutuya sürükle-bırak
  → Birkaç saniye bekle → Site yayında!

ADIM 3: Geçici Link Al
  → Netlify sana bir link verir: örn. amazing-tesla-123.netlify.app
  → Bu linkle siten çalışıyor mu test et

ADIM 4: Kendi Alan Adını Bağla (tozyapi.com.tr)
  → Netlify → Sites → Sitenin adı → "Domain settings"
  → "Add a domain" → "tozyapi.com.tr" yaz
  → Netlify sana DNS ayarlarını gösterir
  → Domain sağlayıcına git (isimtescil.net, natro.com vb.)
  → DNS yönetimine gir → Netlify'ın gösterdiği kayıtları ekle
  → 24-48 saat içinde aktif olur

================================================================
BÖLÜM 3: GITHUB + NETLIFY İLE OTOMATİK YAYINLAMA (ÖNERİLEN)
================================================================

Bu yöntemle dosyaları değiştirdiğinde site otomatik güncellenir.

ADIM 1: GitHub Hesabı Aç
  → https://github.com → Ücretsiz hesap oluştur

ADIM 2: Yeni Repository (Depo) Oluştur
  → GitHub → "New repository" → İsim: tozyapi-web
  → Public seç → "Create repository"

ADIM 3: Dosyaları Yükle
  → Repository sayfasında "uploading an existing file" tıkla
  → Seçtiğin site klasörünün TÜM içeriğini seç ve yükle
  → Commit: "İlk yükleme" → "Commit changes"

ADIM 4: Netlify'ı GitHub'a Bağla
  → Netlify → "Add new site" → "Import an existing project"
  → "Deploy with GitHub" → Hesabına izin ver
  → "tozyapi-web" repository'yi seç
  → Build settings: boş bırak (HTML site)
  → "Deploy site" → Tamamdır!

Artık GitHub'a dosya yükledikçe site otomatik güncellenir.

================================================================

2. E-POSTA:

BÖLÜM 5: FORM ÇALIŞMASI İÇİN FORMSPREE KURULUMU
================================================================

Sitedeki iletişim formu için ücretsiz Formspree kullan:

ADIM 1: https://formspree.io → Ücretsiz hesap aç

ADIM 2: "New Form" → İsim: Toz Yapı İletişim

ADIM 3: Sana bir form ID verir: örn. "xvoeqpla"

ADIM 4: index.html'i aç, form etiketini bul:
   <form ...>
   action="https://formspree.io/f/BURAYA_ID_YAZ" yap

ADIM 5: Formspree dashboard'ında gelen mesajları görürsün
   E-posta bildirimi de gönderilir.
